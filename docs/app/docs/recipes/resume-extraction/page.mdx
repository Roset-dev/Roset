# Resume Extraction

Use this recipe for hiring workflows that need standardized candidate records from mixed resume formats.

## Typical Fields

- Candidate name
- Contact details
- Skills
- Work experience timeline
- Education

## Workflow

1. Upload resume files (PDF/DOCX/image)
2. Wait for transformation completion
3. Extract profile attributes from markdown variant
4. Index extracted fields for filtering and ranking

## Practical Tips

- Normalize job titles and date ranges
- Keep raw snippets for human review
- Use search to validate extracted claims against source text
